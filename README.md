# InnoShop 自有插件 · 私密反馈通道

本仓库是 InnoShop 插件用户（站长）向作者反馈问题的**私密通道**。

## 重要说明

- 本仓库**没有公开 Issue 区**，你在这里提交的每一份报告**只有作者本人能看到**，不会公开显示。
- 反馈入口：点本仓库 **Security（安全）页签 → Report a vulnerability（报告问题）** 按钮，
  或直接访问：<https://github.com/isecmai/innoshop-plugin-feedback/security/advisories/new>
- 提交需要 GitHub 账号（免费注册）；不想注册 GitHub 的用户请直接联系卖家。

## 反馈时请尽量写清（处理快很多）

1. 哪个插件（如：数据分析（分析加强版）/ ExpressTrace 快递轨迹……）+ 插件版本号
2. InnoShop 版本（后台右下角可看）与 PHP 版本
3. 做了什么操作、期望什么、实际发生了什么（能贴报错截图最好）
4. 联系方式（可选）：邮箱，方便作者回访进度

## 适用范围

作者发布的全部 InnoShop 插件，包括但不限于：

数据分析（分析加强版）｜一键SEO｜快递轨迹｜订单售后｜营销中心｜数量阶梯价｜运费模板｜企业微信客服｜邮件发件人名称｜服务图标条｜简单页脚编辑｜采集｜404页面｜商品回收站｜商品发售｜一键分享｜评价图片与视频｜外链图片本地化｜商城增强｜商城问题修复｜货币管家｜地址智能填写｜AI翻译｜登录安全

## 隐私承诺

- 请勿在市场商品页评论区公开贴服务器报错、后台地址等敏感信息。
- 你在仓库里提交的报告仅作者可见；问题修复后会随插件更新发布，报告中不会公开你的身份与站点信息。
